  4. Ouvre l'onglet Environment → ajoute les 3 variables
  5. Choisis le plan Free
  6. Clique Create Web Service · build ~2 min
  7. L'URL sera https://epernay-rugby.onrender.com

Notes

Cold start : Free tier Render met le service en veille après 15 min d'inactivité. 30s pour réveiller au prochain hit.

Neon : Free tier suspend la DB après 5 min inactivité, réveil ~1s. Premier appel API peut paraître lent.

Logs : Cherche Application startup complete dans les Render logs pour confirmer que tout est OK.

Syncs récurrents : Pour automatiser ffr_sync.py (classement) ou sync.py (Tisini), ajouter un Render Cron Job sur le même repo.
